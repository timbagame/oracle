🔮 Oracle API Documentation

Available Endpoints

GET /health
Simple health check - returns basic service status
POST /generate-hash
Generate new game secrets (random hash and game address)
Body: { "gameType": "coinflip" | "giveaway" | "dumbflip" | "snowball" }
Note: For dumbflip and snowball games, also returns the secret key
GET /stats
Detailed statistics and metrics about the oracle service

Service Information

This Oracle API provides game completion services for Solana-based coinflip games.
